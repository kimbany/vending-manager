📖 Invendory 사용 가이드
🎯 Invendory 란?
자판기 재고·매출·순이익을 한 곳에서 자동 관리하는 앱이에요. VMMS 판매 데이터와 쿠팡 구매 내역을 자동 수집해서 정확한 이익까지 계산해줘요.
🚀 초기 설정 (처음 1회)
1️⃣ 회원가입 & 로그인
• 구글 계정으로 간편 로그인
• 로그인 후 설정 > 개인/보안 에서 이름·연락처 등록
2️⃣ VMMS 계정 등록
판매 데이터 자동 수집을 위한 VMMS 로그인 정보 등록이에요.

1. 설정 > 개인/보안 > 🔗 VMMS 계정 > VMMS 계정 등록
2. VMMS 아이디·비밀번호 입력 후 저장
3. 이후 매일 12시·19시 자동으로 판매 데이터 수집

⚠️ 계정 정보는 암호화돼서 저장돼요.
3️⃣ 자판기 등록
1. 설정 > 🏪 자판기 > 위치 추가 (예: "○○고등학교")
2. 해당 위치에 자판기 추가 (단말기번호 입력)
3. 여러 대 있으면 각각 추가 (멀티자판기 / 음료자판기 등)

VMMS 연동돼 있으면 컬럼 배치와 제품 정보가 자동으로 채워져요.
4️⃣ 쿠팡 메일 연동 (구매 자동 수집)
쿠팡 주문 메일이 Gmail 로 오면 자동으로 앱에 반영되는 기능이에요. 1회 설정만 하면 돼요.

1. 설정 > 개인/보안 > ✉️ 쿠팡 메일 연동 > 메일 연동 설정
2. 내 전용 전달 주소 u-xxx@invendory.kr 복사
3. Gmail > 설정 > 전달 및 POP/IMAP > 전달 주소 추가 > 위 주소 붙여넣기
4. 앱 모달에 뜬 "👆 Gmail 전달 승인하기" 버튼 클릭 > Google 페이지에서 확인
5. Gmail > 필터 및 차단된 주소 > 새 필터 만들기
   • 보낸사람: @coupang.com
   • 동작: 다음 주소로 전달 → 위 전달 주소 선택

✅ 이후 쿠팡 주문 메일이 오면 자동으로 앱에 반영됩니다.
📦 재고 관리
쿠팡 데이터 가져오기 (자동 입고)
1. 재고 탭 > 📥 쿠팡 데이터 가져오기 > 날짜 선택 (오늘/어제/1주일/1개월/직접)
2. 가져오기 클릭 → 미입고 구매 내역 표시
3. 각 제품에서 제품 매칭 → 앱 제품과 매핑 (박스당 낱개수 입력)
4. 입고 처리 클릭 → 재고 자동 추가 + 원가 자동 계산

💡 박스당 낱개수: 예) 칸쵸 32개들이 2박스 구매 시 → 박스당 수량 32 입력 → 64개 입고
수기 재고 입력
쿠팡 말고 직접 구매한 재고는 수기로 입력해요.

1. 재고 탭 > ➕ 수기 재고 입력
2. 제품 선택 > 박스당 수량 > 구매 수량(박스) > 구매 총액 입력
3. 자동으로 입고 수량 + 개당 원가 계산해서 표시
4. 입고 확인 클릭 → 재고 반영
제품 상세 보기 (입고/차감 이력)
재고 탭에서 제품을 클릭하면:
• 현재 재고 수량
• 전체 입고 내역 (날짜/수량/원가/판매중·소진/쿠팡·수기)
• 차감 내역 (판매/수기)
• 제품별 수기 입고/차감 가능
📊 판매 & 이익 분석
판매 데이터 확인
판매내역 탭에서:
• 기간 선택 (오늘/어제/1주일/한달/직접 입력)
• 총 판매량 · 총 매출
• 제품 판매 순위
• 시간대별/금액대별 분포
• 건별 판매 내역 (삭제/복구 가능)

VMMS 연동돼 있으면 매일 12시·19시 자동 수집돼요. 수동으로 ⚡ 선택 날짜 데이터 수집 눌러도 돼요.
순이익 확인 방법 (중요!)
이익을 계산하려면 입고 → 차감 순서가 중요해요.

1. 쿠팡/수기로 재고 입고 (원가 등록됨)
2. VMMS 판매 데이터 수집
3. 판매내역 탭 > 📦 이 기간 재고 차감 클릭
4. → 자동으로 FIFO 차감 + 원가 기록
5. → 총 원가 / 순이익 / 이익률 + 제품별 이익 표시

💡 FIFO: 오래된 입고분부터 차감해서 정확한 원가 계산
💡 이미 차감 후 입고를 나중에 했으면 💰 원가 보정 버튼으로 재계산
⚙️ 기타 기능
재고 부족 알림
홈 화면 상단에 자판기별로 재고 부족 제품 자동 표시.
설정 > 개인/보안 > 재고 부족 기준 에서 수량 변경 가능 (기본 5개).
데이터 초기화
설정 > ⚠️ 초기화:
• 📦 재고 초기화
• 🏷️ 제품 초기화
• 📊 판매 내역 초기화
• 🛒 쿠팡 입고 데이터 초기화 (메일 연동은 유지)
• 🗑️ 전체 초기화

⚠️ 복구 불가. 비밀번호 재확인 필요.
과거 쿠팡 주문 가져오기
메일 연동 이전 주문은 Gmail 에서 수동 전달하면 돼요.

1. Gmail > 해당 쿠팡 메일 열기
2. ⋮ > 전달 > u-xxx@invendory.kr 붙여넣기
3. 1~2분 뒤 앱에서 📥 쿠팡 데이터 가져오기 (해당 날짜 선택)
