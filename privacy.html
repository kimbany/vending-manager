개인정보처리방침

시행일: 2026년 4월 28일 · 최종 개정일: 2026년 4월 28일

Invendory("당사", "본 서비스")는 자판기 운영자를 위한 재고·매출 관리 도구로서, 사용자의 개인정보를 소중히 여기며 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 Invendory(invendory.kr)가 어떤 정보를 수집하고, 어떻게 이용·보관·보호하는지를 설명합니다.

1. 수집하는 개인정보 항목

1-1. 회원 가입 및 로그인 시

  • 이메일 주소, 닉네임
  • 구글 로그인 사용 시: Google 계정 식별자(UID), 프로필 이메일, 표시 이름

1-2. 서비스 이용 시 자동 수집

  • 자판기 일련번호, 자판기 위치, 컬럼별 상품 정보, 재고 수량
  • 판매 내역, 매출 데이터, 입고/구매 내역
  • 접속 로그, 기기 식별 정보(브라우저 종류, OS)

1-3. 선택적 권한 — Google Gmail 읽기 (gmail.readonly)

본 서비스는 사용자가 명시적으로 "Gmail에서 직접 가져오기" 기능을 사용할 때에 한해, Google Gmail API의 읽기 전용(readonly) 권한을 요청합니다.

이 권한은 쿠팡(@coupang.com)에서 발송된 주문 확인 메일을 검색·파싱하여 자판기 입고 데이터로 변환하는 목적으로만 사용됩니다.

3. Google 사용자 데이터 처리에 관한 고지 (Limited Use Disclosure)

Invendory의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한된 사용 요건(Limited Use)을 준수합니다.

  • Gmail에서 가져온 메일 본문은 쿠팡 주문 정보 추출 외 어떤 목적으로도 사용되지 않습니다.
  • Gmail 데이터는 제3자에게 양도·판매·공유되지 않습니다.
  • Gmail 데이터는 광고 목적으로 사용되지 않습니다.
  • Gmail 데이터는 인공지능/머신러닝 모델의 학습 데이터로 사용되지 않습니다.
  • Gmail 메일 원본은 본 서비스 서버에 저장하지 않으며, 파싱 결과(상품명·수량·금액·주문일자)만 사용자 본인의 데이터베이스 영역에 저장됩니다.

4. 보관 및 파기

  • 회원 정보: 회원 탈퇴 시 즉시 파기
  • 자판기 운영 데이터: 사용자가 직접 삭제하거나 회원 탈퇴 시 파기
  • Gmail에서 추출한 주문 데이터: 사용자가 입고 처리 후 직접 삭제 가능
  • Gmail 액세스 토큰: 세션 종료 시 즉시 폐기 (서버에 영구 저장하지 않음)
  • 접속 로그: 최대 6개월 보관 후 자동 삭제

5. 제3자 제공

본 서비스는 사용자 개인정보를 외부에 제공하지 않습니다. 단, 다음의 경우는 예외입니다:

  • 사용자가 사전에 동의한 경우
  • 법령에 따라 수사기관 등이 정당한 절차에 따라 요구하는 경우

6. 처리 위탁

안정적인 서비스 운영을 위해 다음 업체에 데이터 저장·처리를 위탁하고 있습니다:

수탁 업체위탁 업무
Google Firebase (Google LLC)인증, 데이터베이스 호스팅, 서버리스 함수 실행
Cloudflare, Inc.이메일 라우팅 (전달 메일 방식 사용 시)

7. 사용자 권리 및 권한 철회

  • 사용자는 언제든 자신의 개인정보 열람·정정·삭제를 요청할 수 있습니다.
  • Google 계정 권한 철회: Google 계정 권한 관리 페이지에서 "Invendory" 항목을 찾아 액세스 권한을 제거할 수 있습니다.
  • 회원 탈퇴: 앱 설정 메뉴에서 직접 탈퇴 가능하며, 탈퇴 시 모든 개인정보가 즉시 파기됩니다.

8. 보안 조치

  • 모든 통신은 HTTPS(TLS)로 암호화됩니다.
  • 비밀번호 등 민감정보는 단방향 해시 또는 AES 암호화 후 저장됩니다.
  • Firebase 보안 규칙을 통해 사용자별 데이터 접근을 격리합니다.

9. 쿠키 및 추적 기술

본 서비스는 로그인 세션 유지를 위해 브라우저 로컬 스토리지(localStorage)와 IndexedDB를 사용합니다. 광고/분석용 쿠키는 사용하지 않습니다.
